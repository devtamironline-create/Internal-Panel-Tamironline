# قراردادِ بک‌اند — امتیازِ تکنسین (اپ تکنسین)

**به:** تیم اپ تکنسین · **موضوع:** نمایشِ امتیازِ تکنسین در پروفایل

## منبعِ امتیاز
امتیاز از **نظرسنجیِ تأییدشدهٔ مشتری** (`crm_order_reviews` با `status=approved`)
روی سفارش‌های همان تکنسین محاسبه می‌شود — همان نظرهایی که ادمین در
`/admin/customer-app/reviews` می‌بیند. مقیاس: ۰ تا ۵.

**قاعدهٔ مهم:** اگر تکنسین **کمتر از ۱۰ نظرِ تأییدشده** داشته باشد، امتیازِ
**پیش‌فرضِ ۲٫۵** برای او در نظر گرفته می‌شود (تا داده کافی جمع شود).

همین امتیاز در **سیستمِ پخشِ خودکارِ سفارش** هم به‌عنوان بُعدِ «رضایت» وزن می‌گیرد.

## فیلدِ جدید در `me`
```
GET /v1/technician/me
{
  "success": true,
  "data": {
    "technician": {
      "id": 12,
      "name": "...",
      ...
      "rating": {
        "score": 4.6,          // ۰..۵ — امتیازِ مؤثر (با احتسابِ قاعدهٔ بالا)
        "reviews_count": 23,   // تعدادِ نظرِ تأییدشده
        "is_default": false    // true یعنی هنوز <۱۰ نظر و score همان ۲٫۵ پیش‌فرض است
      }
    }
  }
}
```

**پیشنهادِ نمایش:** ستاره + عدد (مثلاً «۴٫۶ از ۵»). اگر `is_default = true`،
زیرش بنویسید «امتیازِ پایه تا رسیدن به ۱۰ نظر» تا تکنسین گمان نکند امتیازِ
واقعی‌اش پایین است.

> در پنلِ وبِ تکنسین (`/tech-panel/profile`) این امتیاز از قبل نمایش داده می‌شود.
