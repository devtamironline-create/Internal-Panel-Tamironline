# فرانت — دستگاه/برندِ تاپیک‌های مقالات + بردکرامب

هر تاپیکِ مقاله می‌تواند به یک **دستگاه** و/یا یک **برند** گره بخورد (هر دو
اختیاری). مدیرِ مقالات این را در پنل انتخاب می‌کند:

| مثال تاپیک | دستگاه | برند |
|---|---|---|
| خطاهای لباسشویی بوش | لباسشویی | بوش |
| خطاهای ظرفشویی | ظرفشویی | — |
| بهترین دستگاه‌های بوش | — | بوش |
| عمومی | — | — |

## API

هم `GET /api/bff/v1/blog/topics` و هم `topics[]` داخلِ پاسخِ مقاله
(`GET /api/bff/v1/blog/{slug}` و لیستِ مقالات) حالا این فیلدها را دارند:

```jsonc
{
  "id": 12,
  "slug": "washer-bosch-errors",
  "name": "خطاهای لباسشویی بوش",
  "colors": { "bg": "...", "fg": "...", "border": "..." },
  "device": { "id": 3, "name": "لباسشویی", "slug": "washing-machine" },  // یا null
  "brand":  { "id": 4, "name": "بوش",      "slug": "bosch" },            // یا null
  "breadcrumb": [
    { "label": "خانه",             "href": "/" },
    { "label": "مقالات",           "href": "/blog" },
    { "label": "مقالات لباسشویی",  "href": "/blog?device=washing-machine" },  // فقط وقتی device هست
    { "label": "خطاهای لباسشویی بوش", "href": "/blog/topic/washer-bosch-errors" }
  ]
}
```

## قواعدِ نمایش

- **بردکرامب آماده است**: کافی است `breadcrumb` را رِندر کنید. وقتی تاپیک دستگاه
  دارد، یک پلهٔ «مقالات {دستگاه}» بر اساسِ دستگاه اضافه می‌شود؛ اگر دستگاه نداشته
  باشد آن پله حذف می‌شود. یعنی:
  - `خطاهای لباسشویی بوش` → خانه › مقالات › **مقالات لباسشویی** › خطاهای لباسشویی بوش
  - `بهترین دستگاه‌های بوش` (بدونِ دستگاه) → خانه › مقالات › بهترین دستگاه‌های بوش
- **`href`ها پیش‌فرض‌اند**، با قراردادِ فیلترِ موجود (`/blog?device={slug}`) و صفحهٔ
  تاپیک (`/blog/topic/{slug}`). اگر روتینگِ فرانت فرق دارد، از `device.slug` /
  `brand.slug` / `slug`ِ تاپیک، هر مسیری خواستید بسازید — دادهٔ خام هم هست.
- **URLِ نمایشیِ تاپیک** وقتی دستگاه دارد، بهتر است بر اساسِ دستگاه باشد (مطابقِ
  بردکرامب). برند در متنِ نام و badge استفاده می‌شود.

بدونِ نیاز به تغییرِ سمتِ سرورِ دیگر؛ فقط این فیلدهای اضافه‌شده را در UI استفاده کنید.
