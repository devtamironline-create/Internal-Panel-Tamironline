# Frontend — تعرفهٔ خدمات هر دستگاه (Service Pricing)

قیمت‌ها از پنل مدیریت می‌شوند و به‌ازای **هر دستگاه** هستند. دو اندپوینت برای نمایش
وجود دارد: یکی برای صفحهٔ هر دستگاه و یکی برای صفحهٔ کلیِ `/pricing`.

> همهٔ پاسخ‌ها عمومی و کش‌شونده‌اند: `Cache-Control: public, max-age=600, s-maxage=600`
> (۱۰ دقیقه). بعد از تغییر در پنل، یک revalidate لازم است.

---

## 1) قیمت‌های یک دستگاه — برای صفحهٔ `services/{device}`

```
GET /v1/catalog/devices/{slug}/prices
```

- `{slug}` همان slugِ دستگاه است (lowercase ASCII، مثلِ `washing-machine`).
- اگر دستگاه پیدا نشد یا غیرفعال بود → **404**.
- اگر دستگاه قیمتی نداشت → `items: []` (آرایهٔ خالی؛ سکشن را نشان ندهید).

### نمونهٔ پاسخ
```json
{
  "data": {
    "device": { "slug": "washing-machine", "name": "لباسشویی" },
    "items": [
      {
        "id": 12,
        "title": "تشخیص عیب",
        "price": null,
        "price_label": "رایگان",
        "is_free": true,
        "compare_at_price": null,
        "note": null
      },
      {
        "id": 13,
        "title": "ایاب و ذهاب",
        "price": 400000,
        "price_label": "400,000 تومان",
        "is_free": false,
        "compare_at_price": 300000,
        "note": null
      },
      {
        "id": 14,
        "title": "باز و بست کامل لباسشویی",
        "price": 1000000,
        "price_label": "1,000,000 تومان",
        "is_free": false,
        "compare_at_price": 800000,
        "note": null
      }
    ]
  }
}
```

## 2) همهٔ دستگاه‌ها — برای صفحهٔ `/pricing`

```
GET /v1/catalog/prices
```

فقط دستگاه‌های فعالی که **حداقل یک قیمتِ فعال** دارند برمی‌گردند، به‌ترتیبِ دستگاه.

### نمونهٔ پاسخ
```json
{
  "data": [
    {
      "device": { "slug": "washing-machine", "name": "لباسشویی", "icon": "washer", "tone": "blue" },
      "items": [ { "id": 12, "title": "تشخیص عیب", "price": null, "price_label": "رایگان", "is_free": true, "compare_at_price": null, "note": null }, ... ]
    },
    {
      "device": { "slug": "dishwasher", "name": "ظرفشویی", "icon": "...", "tone": "..." },
      "items": [ ... ]
    }
  ]
}
```

ساختارِ `items[]` در هر دو اندپوینت **دقیقاً یکسان** است.

---

## فیلدهای هر آیتم (`items[]`)

| فیلد | نوع | توضیح |
| --- | --- | --- |
| `id` | number | شناسهٔ یکتا (برای `key`) |
| `title` | string | عنوانِ خدمت (همیشه پر) |
| `price` | number \| null | قیمت به **تومان** (عددِ خام). `null` یعنی رایگان یا توافقی |
| `price_label` | string | **متنِ آمادهٔ نمایش** (مثلِ `400,000 تومان` یا `رایگان` یا یادداشت). |
| `is_free` | boolean | اگر `true` → خدمتِ رایگان |
| `compare_at_price` | number \| null | قیمتِ قبلی (اختیاری — برای خط‌خورده). معمولاً نادیده بگیرید |
| `note` | string \| null | یادداشت (مثلِ «بسته به مدل»)؛ وقتی `price=null && !is_free` نمایش دهید |

### منطقِ نمایشِ قیمت (پیشنهادی)
ساده‌ترین راه: مستقیم از **`price_label`** استفاده کنید (همه‌چیز در آن آماده است).

اگر می‌خواهید خودتان فرمت کنید (مثلاً ارقامِ فارسی)، از `price` (عدد) استفاده کنید:

```ts
function renderPrice(item) {
  if (item.is_free) return 'رایگان';
  if (item.price == null) return item.note ?? 'توافقی';
  return toFa(item.price.toLocaleString('fa-IR')) + ' تومان';
}
```

> توجه: `price_label` با ارقام/کاماهای **لاتین** می‌آید (`400,000 تومان`). اگر سایت با
> ارقام فارسی است، از `price` + فرمتِ خودتان استفاده کنید.

---

## ترتیب و گروه‌بندی

- `items[]` از قبل به‌ترتیبِ درست **مرتب** شده‌اند (`sort_order`) — معمولاً «تشخیص
  عیب» و «ایاب و ذهاب» اول می‌آیند. همان ترتیب را حفظ کنید.
- پیشنهادِ نمایش: یک **جدول/لیستِ دو‌ستونه** (عنوان سمت راست، قیمت سمت چپ). خدماتِ
  رایگان را با یک برچسبِ «رایگان» متمایز کنید.

## یکپارچگی با صفحهٔ دستگاه

این سکشن یک بخشِ **مستقل** است (نه داخلِ پاسخِ `GET /v1/catalog/devices/{slug}`).
آن را با یک fetch جدا بگیرید (`/devices/{slug}/prices`) تا کشِ مستقل داشته باشد و
صفحهٔ دستگاه سبک بماند. اگر `items` خالی بود، سکشنِ تعرفه را رندر نکنید.

---

## نکات مهم دربارهٔ تعرفه‌ها (`disclaimer`) — اختیاری

هر دو اندپوینت ممکن است یک فیلدِ **اختیاریِ سطح‌بالا** به‌نامِ `disclaimer` کنارِ
`data` بفرستند (متنِ یکسان در هر دو — یک مقدارِ سایت‌گستر که در پنل مدیریت می‌شود).

```jsonc
{
  "data": { /* ...بدون تغییر... */ },
  "disclaimer": {
    "title": "نکات مهم دربارهٔ تعرفه‌ها",
    "paragraphs": [
      "قیمت‌های درج‌شده، مربوط به اجرت و دستمزد خدمات هستند و شامل هزینهٔ قطعات نمی‌شوند. ...",
      "اجرت خدمات در تعمیرآنلاین بر اساس لیست تعرفهٔ اعلام‌شده محاسبه می‌شود ...",
      "..."
    ]
  }
}
```

| فیلد | نوع | توضیح |
| --- | --- | --- |
| `disclaimer` | object \| absent | اگر مدیر چیزی در پنل ذخیره نکرده باشد، **اصلاً فرستاده نمی‌شود** → فرانت متنِ پیش‌فرضِ خودش را نشان دهد. |
| `disclaimer.title` | string | عنوانِ باکس. اگر مدیر خالی بگذارد، مقدارِ پیش‌فرضِ «نکات مهم دربارهٔ تعرفه‌ها» می‌آید. |
| `disclaimer.paragraphs` | string[] | هر عنصر یک پاراگراف، به‌ترتیبِ نمایش. هر کدام در یک `<p>` جدا رندر شود. |

- وقتی `disclaimer` نبود → متنِ پیش‌فرضِ داخلیِ فرانت را نشان بده (چیزی نشکند).
- وقتی بود → روی پیش‌فرض **غالب** است (در صفحهٔ دستگاه، device×brand و `/pricing`).
- کش مثلِ بقیهٔ تعرفه است (`max-age=600`)؛ بعد از ویرایش در پنل یک revalidate لازم است.

## خلاصهٔ چک‌لیست
- [ ] صفحهٔ دستگاه: `GET /v1/catalog/devices/{slug}/prices` → اگر `items` پر بود، سکشنِ تعرفه را نشان بده.
- [ ] صفحهٔ `/pricing`: `GET /v1/catalog/prices` → برای هر دستگاه یک بخش (با `device.name` و آیکن).
- [ ] قیمت: `price_label` (آماده) یا `price` (برای فرمتِ فارسی). `is_free` → «رایگان».
- [ ] خالی‌بودن و 404 را هندل کن (سکشن را نشان نده / صفحه را خالی نگذار).
- [ ] بعد از تغییر در پنل، revalidate کن (کشِ ۱۰ دقیقه‌ای).
