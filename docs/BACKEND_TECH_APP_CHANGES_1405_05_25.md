# نامه به تیم توسعهٔ اپ تکنسین — سه تغییر ۱۴۰۵/۰۵/۲۵

**از:** تیم بک‌اند پنل — **موضوع:** حذف پیش‌نویس، هماهنگی بدون توضیح، پرداخت داخل اپ با برگشت خودکار

## ۱) مفهوم «پیش‌نویس» حذف شد

- «پایان سفارش» همیشه **نهایی** است: فاکتور و بدهی همان لحظه ساخته می‌شود.
- ورودی `save_as_draft` در `POST /orders/{id}/status` از این نسخه **نادیده گرفته می‌شود** — اگر اپ هنوز می‌فرستد خطا نمی‌گیرد، ولی اثری هم ندارد. UI پیش‌نویس (چک‌باکس/حالت ذخیرهٔ موقت) را از اپ حذف کنید.
- پیش‌نویس‌های قدیمیِ باقی‌مانده: سرور برایشان همچنان گذار «ثبت نهایی» (همان Completed) را در `allowed_transitions` برمی‌گرداند تا قفل نشوند — این تنها جایی است که اثر پیش‌نویس هنوز دیده می‌شود.

## ۲) هماهنگی = فقط تقویم، بدون توضیح اجباری

- برای وضعیت «هماهنگ شده» دیگر `description` الزامی نیست — فلوی درست: نتیجهٔ تماس → انتخاب روز/بازه از تقویم (`POST /orders/{id}/schedule-visit`) → تمام.
- اگر اپ فرم توضیح را قبل از تقویم نشان می‌دهد، حذفش کنید. `description` اگر ارسال شود همچنان ذخیره می‌شود (اختیاری).
- وضعیت‌هایی که توضیح اجباری دارند (بدون تغییر): معلق (`suspended`)، رد سفارش (`declined`)، ایاب و ذهاب (`transit`) — حداقل ۱۵ کاراکتر.

## ۳) شارژ کیف‌پول داخل اپ + برگشت خودکار

مشکل: تکنسین برای شارژ به پنل می‌رفت و بعد از پرداخت همان‌جا می‌ماند. حل:

- صفحهٔ شارژ را با لینک برگشت باز کنید:

```
https://panel.tamironline.com/tech/wallet/recharge?return={URL-encoded deep link}
```

مثال: `?return=karbalad%3A%2F%2Fwallet%3Frefresh%3D1`

- بعد از پرداخت (موفق/ناموفق)، صفحهٔ نتیجه **۳ ثانیه بعد خودکار** به همان لینک برمی‌گردد + دکمهٔ «بازگشت به اپلیکیشن». پارامترهای `payment=success|failed` و `reference={شماره پیگیری}` به لینک اضافه می‌شوند.
- **در مرورگر خارجی / Custom Tab** باز کنید نه WebView — درگاه‌های بانکی در WebView مشکل‌سازند و deep link برگشت هم از مرورگر تمیز کار می‌کند.
- **امنیت**: لینک برگشت از allowlist عبور می‌کند — `karbalad://` و `tamironline://` و زیردامنه‌های https مجاز از قبل هستند؛ scheme دیگری خواستید اعلام کنید. لینک غیرمجاز بی‌سروصدا حذف می‌شود.
- موجودی نهایی را بعد از برگشت از `GET /v1/technician/wallet` بخوانید — پارامتر `payment` فقط برای UI فوری است.
