# نامه به تیمِ فرانت — تصویرِ Hero اختصاصی و تاگلِ سکشن‌ها در صفحاتِ ترکیبی

## خلاصه

از این به بعد ادمین می‌تواند برای **هر صفحهٔ ترکیبیِ خاص** (device×brand، مثلاً
`/services/washing-machine/bosch`) این‌ها را جداگانه تنظیم کند:

1. **تصویرِ Hero اختصاصیِ همان صفحه** (۲ دسکتاپ + ۱ موبایل، هرکدام با alt) —
   قبلاً تصویر فقط از دستگاه/برند/الگوی سراسری می‌آمد.
2. **روشن/خاموشِ سکشن‌های** «ویدیوها»، «سوالاتِ انجمن» و «مقالاتِ مرتبط»
   به‌ازای همان صفحه (علاوه بر تاگل‌های قبلی).

**قراردادِ API تغییری نکرده** — همان فیلدها و همان شکل؛ فقط منبعِ مقدارها
غنی‌تر شده. به‌احتمالِ زیاد هیچ تغییری در فرانت لازم نیست؛ فقط چند مورد را
تأیید کنید (چک‌لیستِ پایین).

---

## ۱) تصویرِ Hero — همان شکلِ همیشگی

`GET /v1/catalog/devices/{device}/{brand}` → `sections.hero.image`:

```jsonc
"image": {
  "desktop_left":  { "url": "https://…/x.webp", "alt": "..." },
  "desktop_right": { "url": "https://…/y.webp", "alt": "..." },
  "mobile":        { "url": "https://…/m.webp", "alt": "..." }
}
```

- **زنجیرهٔ اولویتِ جدید (per-slot):** رکوردِ همین صفحهٔ ترکیبی ← الگوی
  اختصاصیِ دستگاه ← تصویرِ دستگاه ← تصویرِ برند ← الگوی سراسریِ ترکیبی.
- merge **به‌ازای هر slot جداگانه** انجام می‌شود: ممکن است `desktop_left` از
  override همین صفحه بیاید و `mobile` از دستگاه — این عمدی است.
- هر slot ممکن است `url: null` باشد (مثل قبل) → فرانت همان fallback/طرحِ
  بدونِ تصویرِ فعلی را نگه دارد.

## ۲) تاگلِ سکشن‌ها

همان فیلدهای `enabled` که الان می‌خوانید، حالا per-page هم کنترل می‌شوند:

- `sections.videos.enabled`
- `sections.forum_questions.enabled`
- `sections.related_articles.enabled`

**فقط تأیید کنید** که روی صفحهٔ ترکیبی این سه flag واقعاً رعایت می‌شوند
(اگر `false` بود سکشن رندر نشود) — بقیهٔ سکشن‌ها از قبل همین رفتار را داشتند.

## ۳) تازگیِ کش (خبرِ خوب)

با هر **ذخیره/تغییرِ وضعیتِ** صفحهٔ ترکیبی در پنل، بک‌اند خودش webhookِ
revalidate فرانت را صدا می‌زند با:

- **paths:** `/services/{device}/{brand}` و `/devices/{device}/{brand}`
- **tags:** `page:device_brand` و `device:{deviceSlug}`

پس اگر handlerِ `/api/revalidate` شما همین paths/tags را می‌پذیرد (مثلِ
ویرایشِ page-content که از قبل کار می‌کرد)، تغییراتِ ادمین **بدونِ انتظار
برای TTL** روی سایت دیده می‌شود. اگر صفحهٔ ترکیبی با path دیگری کش می‌شود،
بگویید تا به فهرستِ purge اضافه کنیم.

## چک‌لیستِ فرانت

- [ ] رندرِ هر ۳ اسلاتِ `hero.image` روی صفحهٔ ترکیبی (desktop_left/right + mobile) با alt.
- [ ] تحملِ `url: null` در هر slot (مثل قبل).
- [ ] رعایتِ `enabled=false` برای `videos` / `forum_questions` / `related_articles` در صفحهٔ ترکیبی.
- [ ] پذیرشِ purge با paths/tags بالا در `/api/revalidate` (احتمالاً از قبل درست است).

> موردِ تأیید است.
