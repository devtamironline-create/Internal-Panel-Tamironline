# فرانت — گزارشِ تخلف (محتوای نامناسب)

کاربران باید بتوانند سوال/پاسخِ انجمن و کامنتِ مقالات را گزارش کنند.
بک‌اند آماده است — این سند قراردادِ کامل برای اتصالِ UI است (دکمهٔ ⚑ روی هر
پیام + مودالِ انتخابِ دلیل).

## ۱) دلایلِ گزارش — `GET /v1/forum/report-reasons`

عمومی، کش ۱ ساعته — برای رندرِ داینامیکِ رادیوهای مودال:

```jsonc
{ "data": [
  { "value": "spam",          "label": "اسپم/تبلیغ" },
  { "value": "inappropriate", "label": "محتوای نامناسب" },
  { "value": "wrong-info",    "label": "اطلاعات نادرست" },
  { "value": "duplicate",     "label": "سوال تکراری" },
  { "value": "other",         "label": "دیگر" }
] }
```

## ۲) ثبتِ گزارش — `POST /v1/forum/report`

- **بدونِ auth** (گزارشِ ناشناس مجاز) — throttle: ۵ گزارش/دقیقه بر IP.
- Body:

```jsonc
{
  "target_type": "question",   // question | answer | comment (کامنتِ مقالات)
  "target_id": 12,
  "reason": "inappropriate",   // یکی از valueهای بخش ۱
  "notes": "توضیحِ اختیاری",     // اختیاری، تا ۱۰۰۰ کاراکتر
  "reporter_name": "…",         // اختیاری
  "reporter_email": "…"         // اختیاری
}
```

- پاسخ‌ها:
  - `200 {"ok":true,"message":"گزارش شما ثبت شد. تیم مدیریت بررسی می‌کند."}`
  - تکراری (همان IP، همان هدف، ۲۴ ساعت): `200 {"ok":true,"message":"Already reported"}`
    → UI همان پیامِ موفقیت را نشان دهد (idempotent؛ خطا نیست).
  - هدفِ ناموجود: `404` — `429` هنگامِ عبور از throttle.

### target ها
| target_type | id از کجا | کجا دکمه بگذارید |
|---|---|---|
| `question` | `id` سوال در `GET /v1/forum/questions/{slug}` | هدرِ سوال |
| `answer` | `answers[].id` همان پاسخ | منوی هر پاسخ/دیدگاه |
| `comment` | `id` کامنت در `GET /v1/blog/articles/{slug}/comments` | منوی هر کامنتِ مقاله |

## ۳) بعد از گزارش چه می‌شود؟
- گزارش در **پنل → انجمن → گزارش‌های کاربران** با badge شمارنده می‌نشیند؛
  ادمین می‌بیند، اقدام می‌کند (رد/بررسی‌شده/اقدام‌شده) و از همان‌جا به محتوای
  گزارش‌شده لینک دارد.
- پیشنهادِ UX: بعد از ثبت، دکمهٔ ⚑ همان آیتم را قفل کنید («گزارش شد ✓») —
  سرور هم تکرارِ ۲۴ساعته را idempotent هندل می‌کند.
