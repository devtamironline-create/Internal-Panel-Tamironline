# نامه به تیم فرانت — لینکِ «صفحات ترکیبی» (device × brand) در صفحات دستگاه و برند

> نسخه: 1.0 | موضوع: نمایشِ برندهای پشتیبانی‌شده‌ی هر دستگاه (و برعکس) با لینک به صفحه‌ی ترکیبی

## خلاصه

در پنل ادمین، برای هر **دستگاه** مشخص می‌شود چه **برندهایی** را پشتیبانی می‌کند (و وضعیتِ فعال/غیرفعالِ هر صفحه‌ی ترکیبی در «مدیریت صفحات ترکیبی» کنترل می‌شود). حالا این اطلاعات با **لینکِ صفحه‌ی ترکیبی** در API برمی‌گردد تا فرانت بتواند در صفحه‌ی دستگاه، برندها را با لینک به `/(services)/{device}/{brand}` نشان دهد — و در صفحه‌ی برند، دستگاه‌ها را.

صفحه‌ی ترکیبی = `/services/{deviceSlug}/{brandSlug}` (همان که API‌اش `GET /v1/catalog/devices/{deviceSlug}/{brandSlug}` است).

---

## ۱) صفحه‌ی دستگاه — `GET /v1/catalog/devices/{slug}`

در پاسخ، سکشن `sections.brands.items` حالا برای هر برند این فیلدها را دارد:

```json
{
  "id": 11,
  "name": "آاگ",
  "slug": "aeg",
  "logo": "https://panel.tamironline.com/media/.../aeg.webp",
  "href": "/brands/aeg",
  "combo_href": "/services/gas-cooktop/aeg",
  "combo_active": true
}
```

| فیلد | توضیح |
|------|-------|
| `href` | صفحه‌ی خودِ برند (`/brands/{slug}`) |
| `combo_href` | **صفحه‌ی ترکیبیِ این دستگاه × برند** (`/services/{device}/{brand}`) |
| `combo_active` | آیا صفحه‌ی ترکیبی در پنل **فعال** است؟ (از «مدیریت صفحات ترکیبی») |

## ۲) صفحه‌ی برند — `GET /v1/catalog/brands/{slug}`

در پاسخ، سکشن `sections.devices.items` حالا برای هر دستگاه این فیلدها را دارد:

```json
{
  "id": 5,
  "label": "گاز رومیزی",
  "slug": "gas-cooktop",
  "href": "/devices/gas-cooktop",
  "combo_href": "/services/gas-cooktop/aeg",
  "combo_active": true,
  "icon": null,
  "thumbnail": "https://panel.tamironline.com/media/.../gas.webp",
  "tone": null
}
```

| فیلد | توضیح |
|------|-------|
| `href` | صفحه‌ی خودِ دستگاه (`/devices/{slug}`) |
| `combo_href` | **صفحه‌ی ترکیبیِ این دستگاه × برند** |
| `combo_active` | آیا صفحه‌ی ترکیبی فعال است؟ |

---

## رفتار پیشنهادی در فرانت

- در صفحه‌ی **دستگاه**، بخشِ «برندهای پشتیبانی‌شده» را با لینک به `combo_href` نمایش دهید (به‌جای لینک به صفحه‌ی برند). اگر می‌خواهید فقط ترکیبی‌های منتشرشده لینک‌دار باشند، فقط مواردِ `combo_active === true` را به `combo_href` لینک کنید و بقیه را بدونِ لینک (یا با لینک به `href` برند) نشان دهید.
- در صفحه‌ی **برند** هم به‌همین‌ترتیب با `combo_href`.
- **`combo_active`** منبعِ حقیقت برای «این ترکیبی روی سایت فعال است یا نه» است؛ ادمین آن را در پنل «مدیریت صفحات ترکیبی» کنترل می‌کند.

## نکات
- هیچ فیلدِ قبلی حذف نشده؛ فقط `combo_href` و `combo_active` (و در صفحه‌ی دستگاه، `href` برند) **اضافه** شده‌اند → backward-compatible.
- اگر دستگاه هیچ برندی به‌صورت دستی انتخاب نکرده باشد، طبق رفتار فعلی همه‌ی برندهای فعال برمی‌گردند (و `combo_active` آن‌ها معمولاً `false` است مگر در «مدیریت صفحات ترکیبی» فعال شده باشند).
- میزبانِ تصاویر `panel.tamironline.com` است (در `remotePatterns` داشته باشید).
- کشِ صفحه‌ی دستگاه/برند با ویرایش در پنل purge می‌شود (مسیر + تگ `device:{slug}` / `brand:{slug}`)؛ مطمئن شوید `revalidate_*` پیکربندی شده است.
