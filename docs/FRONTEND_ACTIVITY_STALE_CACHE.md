# نامه به تیم فرانت — «فعالیت زنده» دادهٔ کش‌شدهٔ قدیمی نشان می‌دهد (سمت فرانت)

> اولویت: متوسط | وضعیت: بک‌اند درست است ✅ — اقدام لازم سمت Next/BFF

## علامت

صفحه‌ی `https://stage.tamironline.com/services/gas-stove` در بخش «فعالیت زنده» نشان می‌دهد:

> تعمیر اجاق گاز **پاکشوما** — پاسداران — ۱۷ دقیقه پیش

این ترکیب **نامعتبر و غیرفعال** است (در پنل، صفحه‌ی ترکیبیِ اجاق گاز×پاکشوما `غیرفعال` است).

## چرا این یک باگِ فرانت است (نه بک‌اند)

خروجیِ **مستقیمِ بک‌اند** را گرفتیم:

```
GET https://panel.tamironline.com/v1/activity/recent
```

در پاسخ، **هیچ موردی از «اجاق گاز پاکشوما» نیست** — اصلاً `gas-stove` با برندِ پاکشوما برنمی‌گردد. همه‌ی آیتم‌ها یا ترکیبِ معتبر دارند یا بدونِ برندند (مثل «تعمیر گاز رومیزی»، «تعمیر لباسشویی»). یعنی بک‌اند **فقط ترکیب‌های فعال** را می‌سازد و درست کار می‌کند.

پس «اجاق گاز پاکشوما» که روی سایت دیده می‌شود، از یک **پاسخِ قدیمیِ کش‌شده** می‌آید (مربوط به نسخه‌ی قبلیِ بک‌اند که برند را تصادفی می‌چسباند). فرانت/BFF این پاسخِ کهنه را سرو می‌کند.

## آنچه باید در فرانت اصلاح شود

اندپوینتِ فعالیت عمداً کم‌عمر است:

```
Cache-Control: public, max-age=60, s-maxage=60
```

یعنی هر ۶۰ ثانیه با دادهٔ تازه بازتولید می‌شود. فرانت باید همین را رعایت کند:

1. **fetchِ فعالیت نباید استاتیک/طولانی‌مدت کش شود.**
   - اگر با `fetch()` در Next می‌گیرید: `fetch(url, { next: { revalidate: 60 } })` یا `{ cache: 'no-store' }` (برای داده‌ی زنده مناسب‌تر است). از `force-cache`/کشِ نامحدود استفاده نکنید.
   - اگر از `unstable_cache` استفاده می‌کنید، `revalidate` را ۶۰ بگذارید.

2. **اگر «فعالیت زنده» داخل صفحه‌ی استاتیک (SSG) رندر می‌شود**، در زمانِ build فریز می‌شود و دادهٔ کهنه می‌ماند. این ویجت باید **سمتِ کلاینت fetch شود** (یا صفحه `dynamic`/`revalidate: 60` باشد) تا همیشه تازه باشد.

3. **کلیدِ کش به فیلترِ صفحه وابسته باشد.** صفحه‌ی `/services/gas-stove` فعالیت را با `?device=gas-stove` می‌گیرد؛ مطمئن شوید کش بر اساس همین پارامتر کلید می‌خورد و نسخه‌ی بدونِ‌فیلتر/قدیمی سرو نمی‌شود.

## تستِ تأیید
بعد از اصلاح، `/v1/activity/recent?device=gas-stove` را مستقیم با خروجیِ ویجتِ سایت مقایسه کنید؛ باید یکی باشند و «اجاق گاز پاکشوما» در هیچ‌کدام نباشد.

## سمتِ بک‌اند (انجام‌شده)
- ActivityController فقط از «صفحات ترکیبیِ فعال» (`DeviceBrandPage.is_active=true`) برند می‌سازد؛ ترکیب‌های غیرفعال هرگز نمی‌آیند.
- toggle در combo-manager حالا کشِ خانه/دستگاه/برند را هم purge می‌کند تا تغییرات سریع‌تر منعکس شوند (به‌شرطِ اینکه فرانت کشِ خودش را طولانی نگه ندارد).
